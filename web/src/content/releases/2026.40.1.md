---
date: 2026-09-30
title: Everything is a tab, and a calmer window
summary: The biggest release yet. Terminals, browsers, files and the git panes are tabs you can put anywhere around your session. The sidebar gains Pinned sessions and a ⌘P that finds any session or command, and the whole window is quieter.
---

**Everything is a tab.** A session used to be one terminal with a panel beside it. Now it has three rows of tabs: the main area with the session's own terminal, a column beside it, and a strip under the terminal (⌘J). A tab can be a terminal (⌘T opens one where you are, ⌘D in the column, ⇧⌘D in the strip), a browser, a file, or one of the git and file panes, and any of them can be dragged to any row. ⌘W closes the tab in front of the area you're in, ⇧⌘T brings back the last one you closed, and resting the pointer on a tab shows what's in it: a terminal's last lines, the page, the top of the file.

**A browser beside your work.** ⇧⌘L opens a browser tab. Its address field lists what your sessions are serving and completes as you type, and a port on its own is enough. ⌘L goes to the address, ⌘R reloads from anywhere, the terminal included (change something, ⌘R, look), and the button beside the address opens the page in your own browser.

**Tabs open where you put them.** Files and browsers open in the column until you move one somewhere else; from then on, that kind opens where you last moved one, per session. ⌥-click a file or a server to open it in the main area just this once.

**A calmer window.** Wortel draws its own titlebar now: one flat band with the tabs in it, the desktop showing softly through the sidebar, plain white pages for the terminal and the column, and fewer buttons, each beside what it controls. Panes open and close in one smooth motion, with the terminals resizing once when they land instead of on every frame. The sidebar runs up to the traffic lights as one surface.

**The sidebar, rethought.** Pin the sessions you live in (⌥⌘P, or the "…" that now appears on every row) and they stay in a Pinned section at the top. Sessions in no folder get a section of their own. Rows are roomier, a session that is waiting on you says what for on a second line and for how long, a long name slides into view when you rest the pointer on it, and renaming happens right on the row. Mark as Unread (⇧⌘U) flags a session to come back to. Folder headers lose their path and gain a "+" for a new session in that folder, and a "…" for the rest.

**⌘P finds anything.** Type a few letters of a session's name, folder, branch or directory and Return takes you there. With nothing typed, Return goes back to the session you were in before this one. The same box runs any command in the menus, and ⇧⌘P shows commands only.

**One menu for a session.** The "…" in the titlebar, the "…" on its sidebar row and its right-click menu are the same menu now, with icons: rename, move to a folder, pin, mark as unread, fork onto a branch of its own, show in Finder, copy the path, close. Fork is in the Session menu too.

**Git follows the session, and the work.** The git panes always show the session you're in. When an agent works in a worktree while your terminal stays in the main checkout, the header says so ("sidebar has 16 changes") and one click shows that checkout, for that session, until you go back. The branch list starts with every checkout of the repository, and the commit box is a single line until you start writing.

**You can see where the keyboard went.** Moving between areas with ⌘] and ⌘[ briefly lights the edge of the area you land in, and a list's selection is blue only while that list has the keyboard, grey otherwise, as in Finder.

**Shortcuts you already know.** The layout follows the editors and Codex: ⇧⌘E for files, ⌃⇧G for source control, ⌥⌘R to rename a session, ⌘G for the next match. ⌥⌘E and ⌥⌘G keep working. ⌘/ opens the full list, and the Help menu's search field finds any command by name. ⌘A selects all in a text field or a page.

Also in this release:

- `wortel rename` and `wortel notify` work from any terminal in the session, not only its own.
- The running jobs list is smaller and reads like a menu.
- A click anywhere on a row in the file tree selects it, not only on its name.
- The terminal's padding is closer to the edges, as in iTerm.
