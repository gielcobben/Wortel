---
date: 2026-10-06
title: Lighter in the background, and nothing left behind
summary: Wortel does a fraction of the git work it did, switching sessions no longer makes every agent redraw, and worktrees, stray shells, ssh setup and git helpers are cleaned up instead of piling up.
---

**Much less work in the background.** The source control panel used to re-read every repository it had ever shown each time a file changed, and to count the changes in every worktree on almost every switch. On a big repository with agents busy in a few worktrees, that could keep several cores busy and the fan spinning. Now only the repository you're looking at is read. The others note that something changed and catch up when you come back to them, with a small spinner while they do. The Files pane does no work while it's hidden.

**Switching sessions is lighter.** Moving between two sessions whose side columns differ no longer resizes every terminal in the app, which made every agent redraw its whole screen. A terminal takes its size when you show it.

**Worktrees are cleaned up, safely.** Closing a session in a worktree now says what's in it and what will happen to it, and Session ▸ Clean Up Worktrees… lists every worktree Wortel made. One with nothing unsaved is removed, folder and branch. One with commits that exist nowhere else keeps its branch unless you tick it. One with uncommitted changes, or something running in it, is kept, and Wortel says why. Folders go to the Trash, so nothing is gone for good.

**Nothing left running.**

- When your git settings turn on its file watcher, Wortel no longer starts one for every repository it looks at. They never exited, and piled up.
- Closing a session you hadn't opened since launch now ends its shell, instead of leaving it, and any agent in it, running out of sight.
- A shell Wortel lost track of comes back at launch as a Recovered session if something is running in it, and is closed if it's idle.
- A fetch, pull or push that hangs is stopped after five minutes, and anything git started stops with it when you quit.

**ssh sets up once.** Connecting to a host installs its terminfo the first time only, instead of printing "Setting up xterm-ghostty terminfo" and leaving a folder in /tmp on every connection.

Also in this release:

- Pasted images are cleared from the temp folder after a day.
- If the list of sessions can't be read, it's set aside instead of being overwritten.
