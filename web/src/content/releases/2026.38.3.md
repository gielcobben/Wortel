---
date: 2026-09-14
title: One row is one thing
summary: A command that starts two servers was showing up as one row, hiding the second port and offering a Quit that would have stopped both. Plus a much faster scan, and a list VoiceOver can read.
---

**A command that starts two servers is two rows.** `bun dev` fanning out to `dev:web` and `dev:images` puts both of them in one process group, and Wortel was treating a process group as one job. That is true when a shell starts it, and it is how an agent's jobs arrive, which is why it held up for so long. It is false here: the pair came out as a single row named after whichever started first, carrying their combined memory and showing only the lower of the two ports, with nothing to say the second one existed.

The hidden port was the smaller half of it. That row's Quit would have stopped both servers, from a row naming one. A process group is now split into the separate trees it contains, so each server is its own row, with its own port and its own Quit. A job that is the whole of its group is still stopped as a group; one sharing a group stops only its own processes.

**Pointing at one row no longer highlights several.** The highlight was keyed on the process group, which stopped being unique the moment a group could hold more than one job. The same mistake had reached one other place: quitting a row would have taken its neighbour's row away while that server kept running.

**The cursor stays an arrow.** It was turning into a pointing hand over a row, which is a web habit. macOS keeps the arrow over clickable rows and says "this does something" with the highlight.

**The scan is twice as fast.** It was slower than reading everything about every process on the machine, which is a good sign that something is being done twice, and three things were. Abandoned processes were fully inspected before being filtered on the directory that discarded nearly all of them, so the cheap question is asked first now. Whether a process belonged to a session was recomputed once per session rather than once. And each process had its command line read twice, once to recognise an agent and once to name a job.

**The list reads properly with VoiceOver.** A row was four separate fragments; it is one sentence now, with the port announced as a port, and each Quit says what it stops rather than being one of several identical buttons. The green dot is marked as decoration, because what it means is already in the sentence, and it uses the system green, which follows Increase Contrast.
