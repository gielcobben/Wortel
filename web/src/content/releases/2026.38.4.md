---
date: 2026-09-17
title: A server belongs to its session
summary: Closing a session now stops the servers it started, including the ones that slipped out of the shell. The toolbar shows what the session you are in is serving, right in the middle. And an agent no longer loses its spinner halfway through a turn.
---

**Closing a session stops what it started.** Closing used to hang up the shell and leave the rest to chance. Anything started with `nohup` or `disown`, and any dev server that detaches itself, ignored that and kept running with no session attached, still holding `:3000` with nothing on screen to say so. The close dialog was already telling you "Closing stops" those servers; now it does.

**Wortel remembers where a server came from.** Once a server has been seen running in a session, it stays that session's, even after it leaves the shell. It shows up in that session's list marked as detached, and it stops when the session closes. The record is kept on disk, so quitting and reopening Wortel does not lose track of it either.

**Closing asks when it matters.** A shell sitting at its prompt with a server running behind it used to close without a word. It now asks first, and names what will stop.

**The toolbar says what is running.** The icon is now a status pill in the middle of the toolbar, showing the server by name and its address, `bun dev :3000`, or a count when there are several. It is about the session you are looking at: switch to a session running nothing and the pill goes away.

**The list has room to breathe.** Servers come first, lowest port first, with everything else below. Each row shows its name with the address and memory underneath, and Copy and Stop sit beside it, quiet until you point at them. VoiceOver reads a row as one sentence, with its port spoken as a port.

**An agent keeps its spinner for the whole turn.** Two ways of losing it are fixed. Wortel recognises most agents by their command line, and reading a command line fails now and then on a perfectly healthy process. That failure was being read as "the agent has exited", so Pi, Gemini, Amp and aider could lose their spinner mid-turn and not get it back until they quit. A failed read no longer counts, and it takes two misses in a row, a minute apart, before Wortel believes an agent is gone.

The other was a build. An agent that runs `cargo build` or anything else that reports its own progress looked like an agent that reports its own status, and Wortel stopped watching its screen for good. When that progress ended, the spinner went with it, for the rest of the session. Wortel now keeps watching and picks the spinner back up whenever nothing else is claiming it, without announcing a finished turn for a pause in the middle of one.
