date: 2026-10-07
title: Closing a file takes you back
summary: A file you open from Changes or History returns you there when you close it. And the menus now show what's on and what each command will do, starting with the checkmark on Check for Updates Automatically.
---

**Closing a file takes you back.** Double-click a file in Changes or History, read it, close it, and you're back where you opened it, not on whichever tab happened to sit next to it. If you switched to another tab in the meantime, the neighbouring tab comes forward, as before.

**Menus that say what they'll do.** Check for Updates Automatically and Share Anonymous Usage Data in the Wortel menu now show a checkmark when they're on. Show and Hide commands for the sidebar, the panes and the side column now name what they'll actually do, Pin Session reads Unpin Session for a pinned one, and commands that don't apply right now are greyed out.
