---
date: 2026-09-17
title: A pasted paragraph is one message again
summary: Pasting several lines into an agent no longer arrives as one message per line. Servers an agent starts in its own process group, or hands to the system with nohup, show up in the pill again. And a project named after your agent is no longer mistaken for it.
---

**A pasted paragraph is one message again.** Paste a few lines into an agent's prompt and each line could arrive as a separate submitted message, filling its queue. A terminal only wraps a paste as one block when the program has asked it to, and your sessions survive a Wortel restart while their terminal does not: the new one started with none of the settings the agent still believed were in place. Wortel now remembers what each session's terminal has been told and says it again on reattach, so a paste stays a paste. The same fix covers shift+enter in an agent's prompt, which could turn back into a submit for the same reason.

**A server the agent keeps to itself is still your server.** Some agents run commands in their own process group rather than giving each one its own: goose, Kimi, Factory droid, and Pi through an extension. A dev server started that way was counted as part of the agent, which meant it was missing from the toolbar pill, missing from the list, and not stopped when the session closed. It is now listed on its own, with its address, and stopping it can never reach the agent it was started from.

**A server handed to the system is found again.** `nohup npm run dev &`, the shape agents reach for most, hands the server to macOS the moment the command returns, leaving nothing pointing back at the terminal it came from. Wortel now recognises those by the session they were started in, so they appear in the pill within a scan instead of turning into a leftover nobody owns. This works for anything serving a port, including a plain `python3 -m http.server` in a subshell.

**A project named after your agent is not your agent.** A server in a folder called `claude-demo`, or a vite inside `pi-site`, was read as the agent itself and disappeared from the list along with it. Only the program's own name counts now. Wortel also recognises Kimi, Qwen, droid and Copilot, which previously appeared as ordinary rows with a Stop button on the conversation.

**A row shows a command, not your environment.** An agent that renames its own process left parts of its environment in the row's name, including things like an API token. Rows now drop environment values and show the command.
