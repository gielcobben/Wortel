---
date: 2026-10-30
title: No dot for a turn that never happened
summary: A long Claude Code conversation left idle could light up in the sidebar when Claude compacted it on its own, and idle sessions could light up together after a relaunch. A session now only gets a dot for a turn that really took place.
---

**Idle compaction no longer looks like a finished turn.** Claude Code now compacts a long conversation by itself after it has sat idle for about 54 minutes, so the summary is written before its prompt cache expires. That runs for half a minute with the same spinner as a turn, so Wortel told you "Finished, your move" on a session where nothing had happened and nothing was waiting for you. Wortel now reads what Claude wrote down, sees a compaction, and leaves the session alone.

**Idle sessions stay quiet after a relaunch.** Right after a relaunch, anything that repainted an idle Claude session for a couple of seconds could pass for a short turn, and several sessions could light up in the same second. A real turn always writes to the conversation, so when Wortel is going by the screen alone it now checks there first, and raises no dot if nothing was written. A session is also no longer named from a turn that didn't happen.

**Change Directory no longer waits forever after a compaction.** A move waiting for Claude to finish could take the compaction's summary for a prompt still owed an answer, and never go ahead. It now looks past the summary.
