---
date: 2026-10-21
title: The right colours after sunset, and a calmer Git panel
summary: An agent follows your Mac from light to dark again. The Git panel stays on the session's own folder, and worktree rows show their branch in every repository.
---

**Dark stays dark.** When your Mac switched to dark mode in the evening, Claude Code could stay on its light colours, with pale diff blocks and a white prompt bar on a dark window. It asks the terminal for its background the moment the theme changes, and Wortel answered with the old one. The new colours are now in place before the question arrives.

**The Git panel stays put.** The panel shows the folder the session belongs to, and in a worktree session (New Worktree Session, Fork, Open Branch), that worktree's changes. An agent working in another worktree of the same project no longer pulls it along, and the "changes in …" hint that pointed elsewhere is gone. When you `cd` into a different project, the panel follows you there, so a commit always lands in the project you're in. To look at another worktree, pick it from the worktree chip and press Back to return.

**Branch names in every repository.** In a repository that keeps its branches in git's newer reftable format, worktree rows said ".invalid" instead of the branch. Wortel now reads the branch from there too, still without running git.

Also in this release: the header no longer has an "Open Session" button while you look at another worktree. Back takes you home, and Open Branch (⇧⌘O) opens any branch in a session of its own.
