---
date: 2026-09-30
title: A browser that behaves, and files open where you drop them
summary: The browser tab signs in to Google and Figma, shows a page's own cursors, opens Web Inspector on ⌥⌘I and stops beeping. Drag a file onto any tab row or pane to open it there, and the git header says plainly which worktree you're looking at.
---

**A browser that behaves like one.** Signing in with Google, and sites like Figma, work now: the browser introduces itself the way Safari does, and a page's sign-in window opens as a real window that can report back and close itself. A page's own cursors show, so Figma's hand appears when you pan. Holding a key a page doesn't use, like space to pan a canvas, no longer beeps. ⌥⌘I opens Web Inspector, and ⌥⌘I again puts it away. A page still gets your shortcuts first, as in Safari and Chrome, except quitting, closing, a new session and moving between sessions, which no page can take from you.

**The browser takes the resize.** With a browser in front of the side column, making the window bigger or smaller changes only the browser, and your terminal holds still. With Files, Changes or History in front, the terminal takes it, as before.

**Drag a file where you want it.** Drag a file out of Changes, History or the file tree onto any tab row, or onto a pane that isn't a terminal, and it opens there as a tab. Dropped on a terminal it types the file's path, as it always has, which is how you hand an agent a file.

**One "+" everywhere.** The bottom strip's "+" sits right after its tabs and offers the same menu as the side column's: a terminal, a browser, or one of the git and file panes, opening in that row.

**Worktrees, said plainly.** When the repository has more than one worktree, a chip beside the branch says which one you're looking at, and its list shows what's in each. Looking at another one, an agent's for instance, changes nothing on disk: the header says so, the branch can't be switched from there, and Back takes you home. The branch menu only switches branches now.

**A calmer sidebar.** A session waiting on you is its coloured dot again, without a second line making the list jump each time an agent finishes; rest the pointer on the row to read what it said. The dot for a session that is working is easier to find.

Also in this release:

- History keeps room for the commit subject in a narrow column, letting the author, the hash and then the age go first.
- macOS no longer offers to fill a verification code from Messages or Mail over the terminal. A sign-in page in a browser tab still gets it.
- Agents stay in the right light or dark palette after a restart. A second copy of Wortel, such as a test build, could undo what the running one knew about your sessions; now a second copy brings the running one forward instead.
- Usage reporting now also counts which kinds of tabs are opened and where, whether ⌘P ends in a session, a command or nothing, whether a commit's message was typed or drafted on your Mac, and whether a file preview opened as a tab or a window. Never what is in them. The full list is at wortel.sh/privacy, and the switch is the ⓘ at the bottom of the sidebar.
