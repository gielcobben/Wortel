title: An agent follows light and dark again
summary: An agent in a session that outlived a restart kept painting the colours it picked before the Mac last changed appearance, so dark diff blocks landed on a white screen. Resumed sessions now follow the system appearance again.
---

**An agent follows light and dark again.** An agent asks the terminal once, when it starts, to be told whenever the Mac changes appearance, and from then on it trusts the terminal to say so. Your sessions survive a Wortel restart while their terminal does not, and the new one was never asked, so nothing was ever said. The agent went on painting the palette it chose hours earlier, which is how a dark diff block ends up on a white screen, or a white prompt box on a dark one. Nothing recovered on its own, because the agent had no reason to ask twice. A resumed session now carries that request across and is told what the appearance is as soon as it comes back, so an agent left running overnight is in the right colours in the morning.

This is the same fix as the pasted paragraph in 2026.38.5, one setting further on: a session outlives the app, its terminal does not, and everything the program still believes has to be said again.
