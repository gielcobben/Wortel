title: ⌘-click a link while an agent has the mouse
summary: In Codex and other fullscreen agents, ⌘-click on a URL did nothing and there was no way to select text Wortel's way. ⌘-click now opens the link and ⌘-drag selects.
---

**⌘-click a link while an agent has the mouse.** Codex, and other agents that fill the whole terminal, take the mouse over so they can do their own scrolling and selection. While they had it, ⌘-click on a URL went to the agent and did nothing, unless the agent had made that URL a link itself. URLs in a command, an approval prompt or your own message were stuck. Now holding ⌘ gives the mouse back to Wortel: ⌘-click opens the link, ⌘ over a URL underlines it, and ⌘-drag selects text you can copy with ⌘C, including in Codex's approval prompt, where a plain drag selects nothing. A plain click or drag still goes to the agent, as before.
