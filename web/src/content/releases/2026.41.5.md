---
date: 2026-10-07
title: Every agent back in its own conversation
summary: If your sessions end while Wortel is closed, reopening it brings each agent back into the exact conversation it was in, without the freeze that could hit on the way back. Updates now download quietly and install with one click, and tab and session shortcuts match other Mac apps.
---

**Every agent comes back where it was.** If Wortel's sessions end while it's closed, for example after choosing Stop Running in Background on its Dock icon, reopening Wortel resumes each agent into the conversation it was in. Claude, Pi and Codex come back in their exact conversation, even with two sessions of the same agent in one folder. Other agents continue their latest conversation, as before.

**No freeze on reopening.** Wortel could hang on launch when a session had been busy while it was closed, for example an agent that kept working. It now reconnects right away, however much happened in the meantime.

**A shell that lost its agent gets it back.** When an agent ended while Wortel was closed but its terminal stayed open, the session used to come back as a bare prompt. Wortel now starts the agent again in its own conversation.

**Updates that land.** Updates download quietly in the background. When one is ready, a download icon appears in the sidebar's bottom bar, and Restart Now takes a second or two, with every session back. Automatic checks are on; you can turn them off in the Wortel menu.

**Shortcuts that match other Mac apps.** ⇧⌘[ and ⇧⌘] switch tabs, as in Safari and Xcode. ⌥⌘↑ and ⌥⌘↓ move between sessions. ⌃⌘1, ⌃⌘2 and ⌃⌘3 open Changes, History and Files.

Also in this release: Wortel keeps a short log of how each agent exited, so a session that ends unexpectedly can be explained.
