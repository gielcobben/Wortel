title: Split it anywhere, and mark up what you see
summary: Everything beside the sidebar is now made of splits, each with its own row of tabs. Mark Up (⇧⌘M) lets you point at a page, a file, a diff or an image, write a note around it and copy it for an agent. A beta now says Wortel Beta, so you can tell it from the regular app.
beta: true
---

**Splits, each with its own tabs.** ⌘D splits the split you are in to the right and ⇧⌘D splits it down, each with a new terminal. A tab let go on the edge of a split makes a new split there, and let go on its middle moves into it. Changes and Files still open beside the terminal with ⌥⌘B, and ⌘J still takes you to a terminal under the main one. ⇧⌘↩ zooms the split you are in to the whole window and back, and View ▸ Reset Layout puts every tab back where a session starts with it, closing nothing.

**A tab that asks what it should be.** The + in a split's row, or ⌥⌘T, opens an empty tab listing Terminal, Browser, Changes, History and Files. Click one or press its first letter. ⌘] and ⌘[ walk the splits, ⌃⌥⌘ and an arrow goes to the split on that side, and ⌃⌘ and an arrow moves the tab in front there.

**Mark up what you see.** Mark Up (⇧⌘M) works over a page in a browser tab, a file's source, its diff, rendered Markdown and an image. Click an element of a page, or draw around anything with a box, a pen, an arrow or a highlighter. Your note goes in a bar at the bottom, with each mark in it as a chip. Return copies it as plain text with a picture of each mark, ready to paste to an agent. Nothing is typed or sent for you.

**The browser tab grew up.** ⌘F finds in a page, with Safari's keys. A download is saved to Downloads, named .download until it is whole. It never replaces a file and is never opened, and a button in the tab's header lists what was saved. An .html file opens as the page it makes, reloads when the file changes, and ⌥⌘U shows its source.

**Smaller things.** `wortel split` opens a terminal in a split beside a session, and `wortel split down -- <command>` runs a dev server or a log there. A session made with `wortel new` is now filed right after the session that ran it. A slow start shows a spinner on its empty page. A beta now says "Wortel Beta" in the menu bar, the Dock and Finder, so you can tell it from the regular app. Settings ▸ Beta updates takes this Mac off the beta channel.

**Usage data.** Wortel now counts when mark-up is turned on and when a note is copied: over which kind of preview, roughly how many marks, and whether one was a picked element. It also counts `wortel split`, and a tab opened in a split. Never what was marked, a word of the note, or any file, folder or repository name.
