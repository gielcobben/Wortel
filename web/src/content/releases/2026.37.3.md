---
date: 2026-09-09
title: Pi stays watched
summary: A Pi session lost its spinner, badge and resume a minute after launch, because Wortel looked for a process called pi and Pi runs as node. Fixed for every agent that runs as a script.
---

**Pi is recognised as running for as long as it runs.** The previous release taught Wortel to read Pi's screen for the busy spinner, and it worked for about a minute. Once a minute Wortel checks that each agent it is tracking is still alive, by looking under the session's shell for a process with the agent's name. Pi is a Node script, so its process is called node and no process is ever called pi. The check failed, Wortel decided Pi had quit, and it stopped watching the session: no spinner, no agent badge in the sidebar, and no resume after a crash. The same was true of Gemini CLI and Amp, which also run under Node, and of aider, which runs under Python. The check now also looks at what a process was started with, so a Node process running Pi counts as Pi. Agents that are their own binary, Claude Code, Codex, crush, goose and opencode, were never affected.
