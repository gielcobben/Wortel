## Inline forms

Ordinary prose with **strong emphasis**, *emphasis*, ***both at once***, and
~~struck-through text~~. Inline code is a chip: `git status`, `--flag`, and a
long one like `~/Library/Application Support/Wortel/sessions.json` that may wrap.

A chip beside punctuation is the hard case: `apply`, `commit`; `push`. And one at
the very end of a sentence: `done`.

Links come in three forms: an [explicit link](https://wortel.sh), a bare URL like
https://wortel.sh/docs which is linkified after the fact, and a
[link whose text is itself a URL](https://wortel.sh/other). The cursor over any
of them should be a pointing hand, not an I-beam.

Escapes and entities: \\*not emphasis\\*, a literal backtick `` ` ``, an ampersand
& and an em dash — set in running text.

## A table too wide for the column

Six columns of real content — this is the case that decides how a renderer
handles width. It should take more room than the prose around it, up to a limit,
and wrap inside its cells rather than running off the edge.

| Command | Runs | Reads | Writes | Notes | Safe to repeat |
|---|---|---|---|---|---|
| `bun run dev` | Vite + workerd | `.dev.vars`, `wrangler.jsonc` | nothing | Hot reload on save; the worker restarts on config changes | yes |
| `bun run build` | Astro build | `src/`, `public/` | `dist/` | Fails on a type error before it writes anything | yes |
| `bun run deploy` | wrangler deploy | `dist/`, `wrangler.jsonc` | Cloudflare | Needs `CLOUDFLARE_API_TOKEN` in the environment | no — it publishes |
| `bun run db:migrate:local` | drizzle-kit | `packages/db/migrations` | local D1 | Applies every pending migration in order | yes |
| `bun run db:migrate:remote` | drizzle-kit | `packages/db/migrations` | remote D1 | The one command with no undo | no |
