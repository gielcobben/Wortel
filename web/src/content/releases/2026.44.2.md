---
date: 2026-10-27
title: Sessions named for what you typed, not for a colour
summary: A new agent session could be named "Extract hex color values" or something like it, after the terminal's own answer to a question the agent asked. Sessions are named from your first prompt again.
---

**No more sessions named after a colour.** When Claude Code starts, it asks the terminal what colour its background is, and the answer travels to Claude down the same path as your typing. Wortel reads that path to name a session from your first prompt, and it took the answer for something you had typed. Pressing Return at the folder trust question was enough to send it off as your "prompt", and the session came out as "Extract hex color values" or "Decode hex color code". Wortel now tells the terminal's answers apart from your keys, so the name comes from what you actually asked.

**Esc is just Esc.** After pressing Esc twice to clear Claude's input, the first letter you typed next could go missing from the session's name. It no longer does. A single Esc followed by an arrow or another key is no longer mistaken for Esc Esc either.

**Change Directory waits for you, not for the terminal.** A move waiting for the agent to go quiet now holds off while you type, paste, click or scroll in that session, and no longer mistakes the terminal's answers to the agent for someone typing.
