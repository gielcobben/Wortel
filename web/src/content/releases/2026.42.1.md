---
date: 2026-10-15
title: Worktrees, made simple
summary: Start a worktree session with one shortcut, get to any branch with another, and close a session without losing anything. Fork a session with its changes and its conversation, and give every session ports of its own.
---

**New Worktree Session (⇧⌘N).** A new session in a worktree of its own, on a fresh branch from your default branch, ready at once. Once the session has a name, its branch is named after it too. The files a project needs to run but git ignores, like `.env`, are copied in; list any others in a `.worktreeinclude` file.

**Open Branch (⇧⌘O).** One field for any branch, worktree or pull request. Type a name and Wortel goes to the session already there, continues a closed one, opens the worktree, checks the branch out in a new worktree, or creates it. Each row says which before you press Return, so a branch never gets a second worktree. Type `#123` or paste a GitHub or GitLab link to check out a pull request.

**Closing keeps your work.** Closing a worktree session (⇧⌘W, the ×, or `exit`) puts it away: the worktree, the branch and the agent's conversation all stay. Find it with ⇧⌘O and it picks up where it left off. When there's nothing in it worth keeping, the worktree goes to the Trash instead. Clean Up Worktrees now knows a squash merged branch is merged.

**Fork Session (⌥⇧⌘N).** The session as it is, in a worktree of its own: staged, unstaged and new files, and the agent's conversation, forked. Try something without touching the original.

**Any worktree, whoever made it.** Worktrees you made yourself or with another tool show up in ⇧⌘O and open as sessions, and Wortel never deletes one it didn't make. A repository can choose where its worktrees go, with Worktree Location… in the folder's menu or `git config wortel.worktreePath`.

**Ports of their own.** Every session gets ten ports to itself, the first in `WORTEL_PORT`, so two agents running a dev server in two worktrees don't both want port 3000.

**Know why a session stopped.** A Claude turn that ended on an API error now says it failed, with the error, and one waiting on a question or a plan says it needs you. Both used to read as finished. While any session is waiting on you, a menu bar item shows how many and lists them.

Also in this release: hold ⌘ to see each session's ⌘1 to ⌘9 shortcut on its row; closing the last session leaves an empty window instead of quitting; drop a folder on the sidebar or the Dock icon to open it; the shell in a worktree session starts in its worktree, never in `/`; Claude follows the Mac between light and dark again after Wortel restarts; the git panel names other worktrees after the session in them; very long commands show in the title too; and the pull request button in the git panel is gone, with the network check it made every minute.
