summary: Wortel has a new app icon. A Codex question now shows one notification instead of a stream of them.
---

**A new icon.** Wortel has new artwork in the Dock, in the app switcher and on its notifications.

**One banner per question.** While Codex waits on an answer it blinks its terminal title, and every blink put a fresh "Action required" banner on screen for as long as the question stood. The first one is now the only one. The same holds for anything else that repeats itself, like a program ringing the bell every few seconds: it gets one banner, and a new one only when it has something new to say.
