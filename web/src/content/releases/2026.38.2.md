---
date: 2026-09-14
title: The running list, read properly
summary: A five digit port rendered stacked one digit per line, long commands were truncated into nonsense, and the list of abandoned processes included things nobody would want to stop. All three are fixed.
---

**A port is no longer squeezed out of shape.** `:13337` rendered stacked one digit per line down the row, because the job's name claimed the row's width and left the port nothing to lay out in. An address cannot be split, so it takes its width first now, and the name, which is the only thing on the row that can usefully shrink, is what gives way.

**Long commands truncate where you can still read them.** They were shortened from the middle, which turned `quick.js serve dist --dir ...` into `quick.js serve di...-chat-prototype`. A command reads from the left, so it now keeps its beginning. The same goes for a session heading, which is sometimes a whole sentence, because a session can be named from the first thing you typed into it.

**Abandoned processes have to be worth mentioning.** A `chrome_crashpad_handler` sitting in a project directory at 2.8 MB is not a server anybody forgot to stop, and it was being listed as one. Something with no session left now has to be holding a port you could reach, or be big enough that stopping it is the point. Your own sessions' jobs are still listed whatever they cost, because you started them and they are still yours.

**One icon in the toolbar, and it stays the same.** It used to swap between two different symbols depending on whether anything was serving a port, which made the item harder to find and encoded a distinction the list already draws far better, with a dot and a port on every row. The icon only appears when something is running, so it has nothing left to say beyond that.
