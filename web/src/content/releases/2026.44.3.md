date: 2026-10-29
title: A new session that starts with a command
summary: wortel new can now run a command in the session it opens, so a script can pick a Claude conversation back up in its folder in one line. And a file tab you switch back to is where you left it.
---

**`wortel new` can run a command.** Everything after `--` is typed into the new session's shell as its first line, so `wortel new --cwd ~/code/x -- claude --resume <id>` opens a session in that folder with that conversation picked back up. It works with `--branch`, `--pr` and `--worktree` too, and starts as soon as the worktree is ready. Because the command is typed rather than run in place of the shell, the sidebar tracks an agent started this way like one you started yourself, and when it exits you're at a prompt. The new session's id still goes to stdout. A command that can't be typed safely (longer than 1 KB, or with a tab or another control character in it) is refused with a reason rather than half run.

**File tabs come back where you were reading.** Switching away from a previewed file and back used to start it at the top again. It now opens exactly where you left it, and a file that changes while you're reading no longer pulls you back to where you started.
