title: Terminals kept whole while Wortel is closed, and agents that come back on their own
summary: The process that keeps your shells running now keeps each terminal whole as well, so a session is exactly as you left it after a quit, a crash or hours out of sight. Installing this update restarts every session's shell once, and your agents come back by themselves, each in its own conversation.
---

**This update restarts your shells once.** Installing it ends every session's shell and starts a new one, once, because the part of Wortel that keeps them running has changed. Claude Code, Codex and Pi come back by themselves, each in its own conversation, and your shell history is saved as usual. Anything else that was running, like a dev server, needs starting again. If Restart Now does nothing, quit Wortel with ⌘Q to finish the update.

**Your terminals are kept whole.** Wortel used to rebuild a terminal's screen when it opened, and that could come back narrow, doubled or in pieces. The process that keeps your shells running now keeps each terminal as well, so after a quit, an update or even a crash a session is exactly as it was, scrollback included, with whatever an agent drew while Wortel was closed. A session out of sight for a minute gives its memory back and returns the same way when you open it.

**Agents come back where they were.** After a restart each agent resumes its own conversation, even when several share a folder. One you opened and never typed into starts fresh instead of joining someone else's. An agent that starts while Wortel is closed now tells Wortel what it's doing, like any other, and so does every agent this update restarts.

**Fixes.** Restart Now in the update dialog sometimes did nothing. Wortel now quits by itself a few seconds after you click it. Claude Code started through another command, like `caffeinate -i claude`, now resumes its conversation too.
