---
date: 2026-09-08
title: Sessions name themselves, and a folder is a directory
summary: A session now takes its name from the first prompt you give an agent, whichever agent it is, and keeps it. Folders know which directory they stand for, the git panel takes a selection instead of one row, and one shortcut brings Wortel to the front from anywhere.
---

**A session is named after what you asked for, seconds after you ask.** Until now a row was called after its directory until an agent's turn ended and the on-device model got a look at the screen, and that look tended to produce two or three words about whatever happened to be scrolling past. Now the name comes from the conversation. Claude Code already titles its own conversation from your first prompt and puts that title in the terminal, so Wortel reads it back: the row says "Debug git panel display issues with worktrees" a few seconds after you press Enter, matches what Claude's own session picker shows, and follows `/rename`. Every other agent gets the same thing a different way. Wortel owns the terminal, so while an agent has just launched it watches for the first real line you type, hands it to the on-device model, and names the row from that. No hooks, no config files, nothing leaves your Mac, and the name is set once and held: it changes only when a new conversation starts in that session. A name you type yourself is final and nothing automatic ever touches it again.

- **Worktree sessions are named for the task, with the branch underneath.** A session opened on a branch used to be called after the branch and stay that way. It is now named like any other session, and the branch moves to a second line under the name, with the same glyph as the toolbar's branch chip.
- **A cut-off name shows itself on hover.** Agent names are longer than branch names, so more of them truncate. Hover one and the full name appears as a tooltip, only when it is actually cut off.
- **A folder is a directory.** A sidebar folder used to be a label: "New Session in Wortel" filed the session under Wortel and started it wherever the selected session had last wandered, which looked exactly like it had worked. Folders now carry a directory, new sessions start in it, and the path shows on the folder header. Set it from the header's menu, or press ⌘O to open a folder from disk and get a session in it, filed under the folder that already covers it or a new one named for it. ⌘N beside a worktree session opens in the project, not inside the worktree.
- **The Session menu moves where a Mac app keeps its main menu**, before Edit, and is grouped: starting a shell, folder commands, acting on the selected session, moving between sessions, jumping to one. "New Section" is now "New Folder…", which is what it always was. ⌥⌘N opens a session at home when you want out of the current folder.
- **The git panel takes a selection.** ⌘-click toggles a row, ⇧-click takes a range, ⇧↑ and ⇧↓ do it from the keyboard, and ⌘A takes everything. Stage, unstage and discard act on the whole selection with one confirmation, and dragging a selected file into the terminal carries every selected path.
- **⌃⌥⌘. brings Wortel to the front from any app**, whether it was hidden, buried or minimised. It is a registered hot key, so it needs no Accessibility permission, and the same chord cmux uses, so if you run both, whichever registered first wins rather than a coin flip.
- **⌘W lands on the row above.** ⌘N files a new session right after the selected one, so ⌘N, do the thing, ⌘W now lands back where you started instead of one row further down.
