title: Move a session to another folder
summary: A session can move to another folder, with its Claude conversation coming along. Use Change Directory in the session menu, or wortel cd from the session itself.
---

**Move a session, agent and all.** You ask Claude to start a new project next door, it makes the folder and keeps working there, and the session, its Git panel and its sidebar folder stay behind on the old project. Change Directory in the session menu, or `wortel cd <folder>` from inside the session, now moves it. The shell changes to the new folder, keeping its scrollback, and Claude picks up the same conversation there. The session is filed under that folder in the sidebar (a new folder if none covers it, the way Open Folder makes one), and the Git panel and Files follow.

**It waits for the right moment.** A move never cuts Claude off. It happens once the turn has ended, not while Claude waits on a permission or a question, and not while you're typing into its box. Until then the session's row says where it's going. Claude can ask for the move itself, and Wortel tells it straight away what will happen, including any background task that will stop. Run the command again with another folder to change the destination, or with the folder you're in to call it off.

Claude Code is the agent that can move today. Other agents, and a program running in the foreground like an editor or a dev server, are refused with a reason rather than interrupted.
