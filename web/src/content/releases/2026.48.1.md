---
date: 2026-11-25
title: Files on ⌘P, a preview tab, and links that open again
summary: ⌘P now finds the files in a session's project, and a file you pick in Changes or Files opens in a preview tab. Links, middle-click paste and exit work again after 2026.47.4, and a new session no longer shows its agent starting up.
---

**Links open again.** In 2026.47.4 a ⌘-clicked web link opened nothing, a middle click pasted nothing, and on macOS 15 a ⌘-clicked path outside a repository could hang Wortel. All three are fixed. Selected text is kept for a middle click and no longer replaces what you copied with ⌘C. A long path an agent broke over two rows now opens whole.

**Files on ⌘P.** Once you type, ⌘P lists the files in the session's repository or folder. Return opens one in a tab, and `name:120` opens it at that line.

**A preview tab.** A file you pick in Changes or Files shows in one tab with its title in italics, and the next one takes its place. Double-click to keep it. With the terminal in front a click only selects, so your agent stays in view, and Space opens the preview. The diff under the Changes list can be put away from View ▸ Show Diff in Changes.

**New sessions open clean.** A session that starts an agent used to show the prompt, the command typed on it, then the agent popping in. It now stays an empty page until the agent has drawn, two seconds at most. Keys typed meanwhile reach the agent once it's up, except Return.

**Help on a new Mac.** When there is no agent or no git, the raised hand in the sidebar says so and types the official install line for you to run. A `claude` installed by its own installer is now found in every session. Wortel asks to send notifications the first time it has one, not at launch.

**Claude Code redraws at any width.** New sessions open Claude Code in its fullscreen view, which redraws the whole conversation when the terminal changes size, so a diff drawn while a column was open no longer stays narrow. A renderer you chose in Claude's own settings is kept.

**Safer with what's in the terminal.** A program can no longer read your clipboard. Git in Changes and History no longer runs a diff or signature program that a repository's own config names.

**Smaller things.** Closing a session goes back to the one you were in before it, not the row above. `exit` closes its session again instead of showing a red banner. The font is SF Mono on every Mac: without Apple's separate download it had been JetBrains Mono. An agent can end its own session and worktree with `wortel close`, and Wortel asks you about uncommitted files first. A folded section shows the working dots of a session inside it. A server Claude Code started no longer keeps its session working. ⌘↑ and ⌘↓ jump between prompts. Wortel's source is open, under the GPL.

**Usage data.** After Wortel hung and was force quit, the next launch reports where it was stuck, for how long and roughly how much memory it held, as it does for a crash. It also counts an agent too old to report its state, and a file picked on ⌘P, never which. File, folder and repository names are still never collected.
