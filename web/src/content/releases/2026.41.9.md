---
date: 2026-10-10
title: Agents come back where they were
summary: When the process that keeps your terminals running is stopped, every agent comes back in the conversation it was in, with the flags it was started with. Typing exit ends a session again, and a full restore no longer holds up the window.
---

**The right conversation, every time.** After a `/clear` or `/resume` inside Claude Code, a session that had to be brought back reopened the conversation Claude was started in, not the one it was in. Wortel now keeps track of the conversation while the agent runs.

**Nothing left behind.** When the process that keeps your terminals running was stopped, an agent that happened to finish closing first was taken as one you had quit, and stayed closed. Each terminal now comes back when its own shell ends, and a resume counts as done only once the agent is running again.

**Started the way you started it.** A resumed agent keeps `--dangerously-skip-permissions`, its model, its permission mode, an environment variable in front of it, and a wrapper like `devx pi`. Before, it came back asking for permission at every step. A command line with more than one command in it is typed for you rather than run again.

**Agents found in more places.** Aliases, `npx` and `bunx`, `cd project && claude`, and an agent you suspend with Ctrl-Z and bring back with `fg` are all followed now. `ssh host claude` and `tmux new claude` are no longer mistaken for an agent running in Wortel.

**Typing `exit` ends the session.** A shell that ended used to leave a terminal that did nothing.

Also in this release: a full restore no longer holds the window up for half a second per session; the process that keeps your terminals is replaced once it holds none when it came from an older version, which is what kept Full Disk Access from reaching your shells after an update; a missed reply can no longer hand one session's terminal to another; and prompts are faster in zsh and bash.
