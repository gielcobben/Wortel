date: 2026-10-27
title: A worktree sheet again, and servers in your own browser
summary: New Worktree Session asks for the branch, where it starts and where the worktree goes, in one sheet that Return still answers at once. Servers from the running-jobs list can open in your default browser.
---

**New Worktree Session has its sheet back.** ⇧⌘N opens one small form: the branch, the branch it starts from, and the folder the worktree goes in. A name is already filled in and selected, so pressing Return makes the session straight away, as before, and that name is replaced with one that fits the work once the session has a name. Type your own to name the branch yourself. Location shows where this repository's worktrees go and changes it for the next ones too, the same setting as Worktree Location… in the folder menu.

**Open servers in your browser.** A server in the running-jobs list opened in a tab inside Wortel. Turn on Open Servers in Default Browser in the View menu, or Always Open in Browser on a server's right-click menu, and a click sends it to Chrome, Safari or whichever browser is your default. The menu still offers both, for the times you want the other one.

**Tab previews in dark mode.** The preview card you get when you rest on a tab kept a white background after switching to dark mode, with the terminal's grey text on it barely readable. It now follows the appearance, the box and its edges both.
