## Updates

Wortel checks for updates and can install them itself, through Sparkle. Updates
are signed, and the app verifies that signature before installing anything. See
[Privacy](/privacy) for what an update check records.

You can turn automatic checks off. Updates then stop arriving, including
security fixes.
