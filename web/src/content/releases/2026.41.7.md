---
date: 2026-10-08
title: Terminals that come back on their own
summary: If something outside Wortel stops your terminals while it's open, Wortel now starts them again with every agent back in its conversation, and tells you what happened. The branch list says where each branch is checked out, and git's errors are written in plain words.
---

**Terminals that come back on their own.** An app you open from a Wortel terminal can take Wortel's terminals with it when you force quit it from its Dock icon. Wortel used to keep showing those terminals as if nothing had happened, and the agents in them were lost. Now Wortel notices right away, starts each terminal again and brings every agent back into the conversation it was in. A message says when it happened, what came back, and what didn't, like a dev server you'll need to start again.

**Branches, and where they are.** The branch list now groups branches by what a click can do: this folder, branches checked out in other folders, branches to switch to, and remote ones. A branch an agent has in its own folder shows that folder, and clicking it shows that folder here. When nothing there can be lost, Bring Here moves the branch into the folder you're in.

**Git errors you can read.** When git refuses something, the Changes pane and the branch list say what happened and what to do about it, in plain words, and you can dismiss the message.

**The pull request in the header.** If the branch has an open pull request on GitHub, the header shows it, and one click opens it. A pushed branch with none offers Create PR. This uses the `gh` command, when it's installed and signed in.

**Stop All.** With two or more things running in a session, the heading of its running list offers Stop All.

Also in this release: a branch name typed with spaces for a new worktree session becomes one git accepts. A session whose folder was deleted says so under its name. And Wortel does less work while it's behind other apps, especially in repositories with many worktrees.
