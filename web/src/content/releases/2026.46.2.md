date: 2026-11-09
title: Back and Forward, through sessions and tabs
summary: Back and Forward walk the places you've been, from Changes to a file to another session and back. Fewer ways to start a session, a sidebar whose shortcuts follow what you see, and links that ask before they open another app.
---

**Back and Forward.** ⌃⌘[ and ⌃⌘], or the arrows at the top of the sidebar, take you back through where you've been, the way a browser does. Not just sessions: the tabs inside them too, so Files, then Changes, then a README, then another session is a trail you can walk back the way you came. A tab or session you've closed is skipped, and the arrow dims when there's nowhere left to go.

**Four ways to start a session.** ⌘N, ⌥⌘N for one at home, ⇧⌘N for a new worktree and ⌘O for a folder. Fork Session, Open Branch, New Folder and Change Directory are gone, with `wortel fork` and `wortel cd`. An existing branch or pull request is still one step away: type its name or `#123` in the New Worktree sheet, or use `wortel new --branch` or `--pr`. Archived sessions, and worktrees no session is in, now show up in ⌘P as soon as you type.

**The sidebar's shortcuts follow what you see.** ⌘1…⌘9, ⌥⌘↑ and ⌥⌘↓, and the session picked after you close one all go by the rows as they're drawn, so they agree with Sort Unread First and skip folded sections. A session dropped on a folder's name now lands at the top of it instead of out of sight at the bottom.

**Links ask before another app opens.** A page in a browser tab can no longer open Mail, Zoom or any other app on its own: you get "Open “Mail”?" first. A link in a Markdown preview that points at an app shows it in Finder instead of starting it.

**Cleaning up worktrees keeps what it should.** Clean Up Worktrees only forgets an archived session when its branch really was deleted, and checks once more that nobody is working in a worktree as it removes it.

**Fixes.**
- Discarding a file with brackets in its name, like `app/[id]/page.tsx`, could also discard other files whose names happened to match it. It now means that one file only.
- A removed line starting with `--` (a SQL comment, say) or an added one starting with `++` was dropped from the diff. Every line now shows.
- `wortel new --worktree` waits as long as a big repository needs, and gets an answer straight away if you close the session while it's being prepared.
- If Wortel can't read its saved list of sessions at launch, it no longer takes that to mean you have none, so the shells still running in the background are left alone.
- macOS's own Window shortcuts (🌐⌃F to fill the screen, 🌐⌃C to centre) now work while a terminal has the keyboard.

**Smaller things.** The tab in front lets the window's colour through, like the selected session does. Line numbers on added and removed lines are easier to read. A long branch name no longer stretches the git panel's menu. And a session's menu reads Pin, Rename, Mark as Unread, Colour, then Copy Path and Show in Finder.
