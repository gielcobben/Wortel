---
date: 2026-09-09
title: Pi shows it is working, and a path in a name is not a folder
summary: An agent that reports nothing, Pi out of the box, now gets a busy spinner in the session you are watching and a turn-end dot when you are not. A generated name with a slash in it stays one row instead of becoming a folder.
---

**Pi finally shows it is working.** Pi ships with its progress reporting switched off, so Wortel had to read its screen to tell working from waiting, and that reading failed in two ways. It never watched the session you had selected, on the theory that you could see for yourself, so the one place you actually watched Pi work showed nothing. And every message Pi draws is wrapped in terminal marks that made the core believe a command had just finished, which switched the spinner off mid-turn and, with it, the "finished, your move" dot that follows a turn. Both are fixed. The selected session is watched like any other, with your own typing, pasting, clicking and scrolling discounted so a long prompt never reads as the agent at work, and a finished-command signal that arrives while an agent is running is ignored, since the agent, not your shell, still has the terminal. Expect the spinner a few seconds after Enter: this is Wortel guessing from the screen, and it waits for two changed frames before it commits.

- **A slash in a generated name no longer makes a folder.** Session names come from your first prompt or the agent's own title, and both are full of paths. "Debug web/src build" was being read as a session called "src build" inside a new folder called "Debug web". Generated names now use a look-alike slash that the sidebar does not treat as a folder separator, so the path still reads as a path. A slash you type into a name yourself still moves the session into that folder, as before.
- **Quitting an agent no longer raises a "Command finished" dot.** The finished-command signal at an agent's exit was being reported like any long shell command. It counts as the agent leaving, not as a command worth flagging.
- **This applies to every agent that reports nothing**, so opencode, goose and aider gain the spinner in the selected session too. Agents that announce themselves, Claude Code, Codex, Gemini, crush and Amp, are unchanged.
