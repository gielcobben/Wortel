---
date: 2026-11-03
title: One session can run the others
summary: The wortel command can now list your sessions, read their screens, type into them and wait for them, so an agent can start another and follow it to the end. Plus your prompt history on ⌘Y, several sessions selected at once, and notifications that say what the agent answered.
---

**`wortel` reaches every session, not just its own.** `wortel list` shows your sessions and what each is doing. `wortel read <session>` prints what's on its screen, and `--lines 50` takes the last 50 lines. `wortel send <session> "text" --enter` types into it the way a paste would, so a prompt of several lines arrives as one. `wortel wait <session>` waits until the agent in it has finished its turn, until some text appears (`--for READY`) or until it exits, and exits with 124 if the time runs out. A session can be named by its id or its name, and `wortel new` already prints the new session's id, so one agent can start another, give it a task, wait for it and read the answer.

**Your prompt history on ⌘Y.** Everything you've typed to Claude Code, Codex and Pi, from any session and any project, with this project's prompts first. Pick one and it goes into the session's input without being sent. Wortel keeps none of it itself: it reads the history the agents already keep.

**Select several sessions at once.** ⌘-click adds a session, ⇧-click takes a range, and right-clicking the selection closes, pins, moves, marks or colours all of them. Esc goes back to one. And View ▸ Sort Unread First lifts the sessions that want you to the top of each section, without touching the order you dragged them into.

**Notifications say what the agent answered.** Instead of "Finished, your move", a notification now starts with the agent's answer, and a question shows the question.

**Wortel notices when you've walked away.** A session you had open in front used to count as seen, even if you'd left before the agent finished. After a minute with no keyboard or mouse, it now gets its dot and its notification like any other.

**No stray characters after a relaunch.** Reattaching a session replays what it printed while Wortel was closed, and the terminal used to answer the old questions in there again (where's the cursor, what's the background colour), which could land in an agent's prompt as `^[[24;1R`. Those answers are now dropped.
