**More than one window.** Window ▸ New Window (⇧⌘N) opens a second window with a sidebar of its own. Drag a session onto the other window's sidebar to move it there, or out of the window to give it one of its own; it keeps running as it is. A session's menu has Move to New Window and Move to Window, and Window ▸ Merge All Windows puts everything back in one. Closing a window closes its sessions, asking first if something is running in them.

**New Worktree Session is ⌥⇧⌘N now**, since ⇧⌘N opens a window.

**Restart agents that were already running.** Claude Code and Pi sessions already running when you update won't show when they're working until you restart them. They ask whether the terminal is listening only when they start.
